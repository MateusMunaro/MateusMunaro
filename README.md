- [**Code-in**](https://github.com/MateusMunaro/tcc) — Monorepo for an AI coding-agent platform: React frontend, Bun/Elysia API, Python worker over Redis, Rust CLI. Runs with a single `docker compose up`.
- [**Cognita**](https://github.com/MateusMunaro/cognita) — Desktop command center for Claude Code infrastructure. Manage skills, MCP servers and hooks offline. Rust + Tauri 2, React 19.
